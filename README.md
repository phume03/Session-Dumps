# Session Parser #
A tool for dumping the contents of session files, written in Python. It was created to solve the issue of retrieving data from files written and encoded in SNSS encoding. This tool is a script that provides a clean way of extracting useful information (like the active tab) from a running or saved chrome session. It's creation was necessitated by irrecoverable Edge sessions due to some kind of corruption in the session handover mechanism between browser restarts.
